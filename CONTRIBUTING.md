**CONTRIBUTING GUIDELINES**

This project is developed as part of a university System Programming course.

**CONTRIBUTIONS**

Contributions to this project are limited to the official project team members.
External contributions are not expected.

All changes should be made using GitHub branches and merged through pull requests.
Each pull request should have a clear description of the changes made.

**CODE STYLE**

The project is written in C++.
Code should be clear, readable, and consistent with existing project structure.
Basic formatting and meaningful variable names should be used.

**COMMITS**

Commit messages should be short and descriptive.
Each commit should represent a single logical change.

**ISSUES**

Issues are used only for internal project tracking and task management.
